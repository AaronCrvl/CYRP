# Can You Repeat, Please? (CYRP)

CYRP is an AI-powered meeting assistant designed to turn meeting recordings and live conversations into useful, searchable notes.

## Planned features

- Upload audio or video recordings, with support for live transcription.
- Transcribe conversations and identify individual speakers.
- Generate meeting summaries, action items, and sentiment analysis with AI.
- Receive real-time processing updates in the application.

## Planned technology

- **Backend:** C# and ASP.NET Core Web API, with SignalR for real-time updates and background processing.
- **Frontend:** React, Vite, and Tailwind CSS.
- **AI:** OpenAI API or a local language model.

## Project structure

- `cyrp.api/` — ASP.NET Core API.
- `cyrp.ui/` — React frontend.
- `docs/` — Project documentation and design materials.

The project is under development; features and architecture may change.
