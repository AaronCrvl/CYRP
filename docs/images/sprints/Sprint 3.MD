# Sprint 3 — Meeting notes and search

**Duration:** 1 week  
**Goal:** Make transcripts useful and searchable.

- Generate a concise summary and action items from a transcript.
- Let users combine selected recordings as context for one AI-generated result.
- Save transcripts and generated notes alongside recordings in browser storage.
- Search meeting titles, transcripts, summaries, and action items.

**Done when:** A user can find a meeting and review its transcript, summary, and action items after refreshing.
