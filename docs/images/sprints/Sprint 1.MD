# Sprint 1 — Frontend and browser file library

**Duration:** 1 week  
**Goal:** Build the meeting workspace and keep recordings in the browser.

- Create a clean, responsive meeting dashboard.
- Add audio/video selection, drag-and-drop, and file previews.
- Store recordings and meeting metadata in IndexedDB; support rename and delete.
- Allow selecting multiple recordings for one AI request.

**Done when:** A user can add recordings, refresh the page, and still find and select them without uploading them to the backend.
