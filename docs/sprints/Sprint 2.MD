# Sprint 2 — AI transcription

**Duration:** 1 week  
**Goal:** Turn selected recordings into transcripts.

- Add a backend endpoint that accepts selected browser files for processing.
- Connect one AI provider for transcription and speaker labels.
- Read provider credentials from server configuration, never the frontend.
- Show queued, processing, completed, and failed states.

**Done when:** A user can submit one or more recordings and view their transcript and speaker labels. The backend does not retain uploaded files.
